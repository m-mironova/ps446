List of replication files:
- "analysis_experiment.R": R script to produce all results related to the experiment
- "analysis_pretest.R": R script to produce all results related to the pretest
- "balance_tests.R": R script to produce the covariate balance graphs for the experiment
- "codebook.pdf": codebook for the experiment and the pretest
- "experimental_data.csv": dataset for the experiment
- "pretest_data.csv": dataset for the pretest
- "state_population.csv": complementary dataset to produce Figure S1
