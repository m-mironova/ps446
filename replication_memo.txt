The replication files relied on a Stata do-file to set up the working directory and load the data into the environment. Despite this, the rest of the code (used to create the graphs, perform analysis) was in R. Since I did not have an app to read .do files pre-installed, I opted to push the replication files to the remote repository and use the displayed version of the .do file accessible through the web version of GitHub to rewrite the code in R.

While rewriting the code, the main concern (aside from accurately translating from a programming language I have no experience with) was the creation of new data frames where Stata, to my understanding, uses and reuses multiple versions of the same data frame. In particular, I was concerned that the names I would assign to these data frames would not match those in the replication R files. This does not appear to have caused any problems at the current stage of replication, however, given that I only replicated Figure 1, it is possible that, in other parts of the data set, I would have run into more issues.
